# Collectors

Сбор фактов о компьютере. Сборщик возвращает нормализованные данные, источник и ограничения покрытия; он не принимает решение об исправлении проблемы. Реализации пока нет.

| Каталог | Область ответственности |
| --- | --- |
| `common/` | Общие файловые метаданные, доступные метрики через стандартную библиотеку и планируемый `psutil` |
| `macos/` | Штатные API и утилиты macOS, подписи, доступные признаки автозапуска и системные особенности |
| `windows/` | Windows API, фиксированные PowerShell-скрипты, подписи и доступные сведения встроенной защиты |

Платформенный вспомогательный скрипт располагается рядом со своим сборщиком, например в `windows/scripts/` при появлении необходимости. Скрипт имеет известное содержимое и проверенные параметры; модель не пишет его во время диагностического вызова.

Обязательны лимиты времени, размера вывода и объёма обхода, безопасная отмена и обработка отказов в доступе. Не следовать бесконтрольно ссылкам, не загружать облачные файлы и не читать содержимое личных документов для оценки занимаемого места. Системный вывод по возможности структурированный; ошибки локализации не маскируются.

Процессы могут исчезать между запросами; PID рассматривается вместе со временем старта. Частичный ответ является нормальным исходом. Нет автоматического повышения прав, фонового мониторинга и сетевой проверки репутации.
