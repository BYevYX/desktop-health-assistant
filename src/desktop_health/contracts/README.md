# Contracts

Общие модели и интерфейсы будущей Python-реализации. Платформенных подкаталогов нет: контракт должен оставаться одинаковым на обеих ОС. Реализации пока нет.

Планируемые группы: capabilities, запрос и область сбора, факт и его источник, покрытие, снимок, идентичность процесса, диагностический вывод, рекомендация и конверт результата. Интерфейсы сборщиков и анализа описываются через типизированные протоколы.

В контрактах задаются версия схемы, UTC-время, единицы, допустимые статусы, причины пропусков и ссылки выводов на факты. Неизвестное значение отличается от нуля. Ограничения результатов нельзя сводить к одному флагу успеха.

Этот слой не импортирует MCP SDK, платформенные API или реализации других слоёв. Публичная сериализуемая модель может содержать меньше сведений, чем внутренние факты: раскрытие чувствительных полей регулирует `policy/`.

См. [архитектуру и конверт результата](../../../ARCHITECTURE.md).
