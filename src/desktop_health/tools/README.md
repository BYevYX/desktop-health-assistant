# MCP tools

Тонкий типизированный интерфейс между MCP-клиентом и диагностикой. Реализации пока нет.

- `common/`: общие инструменты со стабильными именами и схемами на обеих ОС.
- `macos/` и `windows/`: место только для необходимых платформенных расширений; одинаковые инструменты здесь не дублируются.

Предлагаемые имена: `get_capabilities`, `get_system_snapshot`, `analyze_storage`, `sample_performance`, `plan_cleanup`, `inspect_processes`.

Обработчик проверяет схему, область, сроки и лимиты; вызывает переданные ему интерфейсы сборщиков; передаёт факты в анализ; минимизирует результат и возвращает общий контракт. Входные параметры не могут отключить серверные ограничения. Аннотации MCP об операции на чтение документируют поведение, но не заменяют контроль в коде.

Инструменты не принимают произвольную команду, не содержат низкоуровневых системных вызовов и не возвращают уверенный вывод при недостаточных данных.

См. [архитектуру и проект API](../../../ARCHITECTURE.md).
