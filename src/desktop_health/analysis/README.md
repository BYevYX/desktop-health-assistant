# Analysis

Чистые расчёты и диагностические правила над переданными фактами. Реализации пока нет.

- `common/`: ранжирование ресурсов, сводки, общие правила очистки и анализа процессов.
- `macos/`: интерпретация специфичных фактов macOS, без вызова ОС.
- `windows/`: интерпретация специфичных фактов Windows, без вызова ОС.

Вход — модели из `contracts/` и явные параметры контекста. Выход — выводы с идентификатором правила, ссылками на факты, уровнем внимания, уверенностью и ограничениями. Одни и те же входные данные должны давать один и тот же результат.

Запрещены доступ к файловой системе, сеть, subprocess и неявное чтение текущего времени. Выбор набора платформенных правил выполняет точка сборки в `mcp/`.

Отсутствующие факты не превращаются в нули или признаки безопасности. Отсутствие подписи не равно вредоносности. План очистки содержит рекомендации и неопределённость оценки, а не разрешение на удаление.

См. [архитектуру](../../../ARCHITECTURE.md).
