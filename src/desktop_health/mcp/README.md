# MCP runtime

Точка запуска и сборки приложения. Пока не реализована.

- `common/`: stdio-транспорт, настройки, регистрация инструментов, жизненный цикл, отмена, временные снимки и очистка состояния.
- `macos/`: создание и связывание адаптеров и правил для macOS.
- `windows/`: создание и связывание адаптеров и правил для Windows.

Runtime определяет платформу один раз, проверяет возможности и передаёт реализацию через интерфейсы. Платформенные библиотеки импортируются только при выборе соответствующего адаптера. Отсутствие необязательного источника отражается в capabilities.

Диагностические расчёты принадлежат `analysis/`, системные обращения — `collectors/`. `stdout` используется только для MCP, журналы — `stderr`. Сервер не запускает службу, не открывает HTTP-порт и не повышает права автоматически.

Будущая поставка и установка описаны в [packaging](../../../packaging/README.md). Основной документ: [ARCHITECTURE.md](../../../ARCHITECTURE.md).
