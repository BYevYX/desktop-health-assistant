# Проверки

Это план проверок, а не готовый набор тестов. Исполняемая реализация пока отсутствует.

- `common/`: контракты, правила анализа, лимиты, минимизация данных, MCP-протокол и сценарии на обезличенных фикстурах.
- `macos/`: адаптеры, реальные разрешения и запуск пакета на macOS.
- `windows/`: адаптеры, реальные разрешения и запуск пакета на Windows.

При реализации использовать pytest; форматирование и линтинг — Ruff, статическая проверка типов — mypy. Проверять поведение, а не повторять код в тесте.

Основные негативные случаи: отказ в доступе, частичные сведения, отмена, тайм-аут, исчезнувший процесс, повторное использование PID, символические ссылки и reparse points, пути с пробелами и Unicode, облачные заглушки, недоверенные строки и утечки чувствительных данных.

Фикстуры не должны содержать реальные снимки компьютера, персональные пути или секреты. Моки ОС не подтверждают платформенную совместимость: каждый заявленный релиз проверяется на нужной ОС и архитектуре процессора, включая запуск без заранее установленного Python.

На текущем этапе достаточно проверки ссылок, структуры каталогов и согласованности документации. См. [архитектуру](../ARCHITECTURE.md).
