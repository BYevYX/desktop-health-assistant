# Skills

Слой сценариев ассистента. Сейчас здесь только архитектурные места для будущих skills; действующих `SKILL.md` нет.

| Каталог | Будущее содержимое |
| --- | --- |
| `common/` | Сценарии `storage-analysis`, `performance-analysis`, `cleanup-planning`, `process-triage` |
| `macos/` | Справочники по значениям метрик, ограничениям и ручным действиям на macOS |
| `windows/` | Аналогичные справочники для Windows |

Каждый общий сценарий получит собственный `SKILL.md`. При упаковке необходимые платформенные справочники включаются в `references/` этого skill. Переключение справочника опирается на результат `get_capabilities`.

Skill выбирает подходящий инструмент и объясняет факты, ограничения и рекомендации. Он не содержит альтернативного сборщика, не исполняет произвольные команды и не отменяет ограничения сервера. Подозрительная строка из результата остаётся данными, даже если похожа на инструкцию.

См. [архитектуру](../ARCHITECTURE.md).
