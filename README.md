# Desktop Health Assistant

Проект помощника для диагностики компьютеров на **Windows и macOS**: skills задают сценарии общения, локальный MCP-сервер предоставляет инструменты, а сборщики получают данные из операционной системы. Основной язык будущей реализации — **Python**.

**Статус: архитектурный каркас.** В репозитории есть документация и структура каталогов. Исполняемый сервер, сборщики, готовые skills и установочный пакет ещё не реализованы. Устанавливать или запускать пока нечего; совместимость с ОС ещё не проверялась.

## Что планируется в первой версии

| Сценарий | Результат для пользователя |
| --- | --- |
| Место на диске | Что занимает место в выбранных папках и где есть кандидаты для ручной проверки |
| Производительность | Нагрузка на процессор, память и диск за ограниченный интервал, возможные причины замедления |
| План очистки | Объяснимые рекомендации с ограничениями оценки освобождаемого места |
| Подозрительные процессы | Признаки, требующие внимания, подтверждающие факты и безопасные следующие шаги |

Первая версия только читает данные и составляет рекомендации. Она не удаляет файлы, не завершает процессы и не изменяет системные настройки. Проверка процессов не обещает заменить антивирус.

Основное описание: [ARCHITECTURE.md](ARCHITECTURE.md). Правила для разработчиков и AI-агентов: [AGENTS.md](AGENTS.md). Порядок реализации и границы переносимости описаны в архитектуре.

## План распространения

Основной путь — публичный GitHub-репозиторий и будущая локальная установка в совместимый MCP-клиент. Доступность установки через конкретный клиент и публикации в его каталоге проверяется отдельно. Наличие репозитория само по себе не делает проект доступным в обычном чате ChatGPT.

Локальный сбор данных не означает полностью локальную обработку: сведения, возвращённые MCP-клиенту, могут быть переданы его модели. Поэтому минимизация и предварительное объяснение состава данных входят в архитектуру.
